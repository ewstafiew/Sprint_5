# Sprint_5 — UI-автотесты для сервиса «Доска»

UI-автотесты на Selenium + pytest для учебного сервиса https://qa-desk.education-services.ru/

## Структура

- `conftest.py` — фикстуры: `driver` открывает Chrome с главной страницей и закрывает его после теста; `new_user_driver` регистрирует нового пользователя и оставляет его авторизованным (для теста создания объявления: в профиле по 3 объявления на странице, удалить объявление нельзя, поэтому у пользователя должно быть пусто)
- `locators.py` — локаторы элементов
- `data.py` — тестовые данные и URL
- `helpers.py` — генерация нового email для регистрации и названия объявления
- `tests/` — тесты

## Тесты

| Файл | Класс | Что проверяет |
|---|---|---|
| `tests/test_registration.py` | `TestRegistration` | успешная регистрация; email не по маске; повторная регистрация существующего пользователя |
| `tests/test_login.py` | `TestLogin` | вход существующего пользователя |
| `tests/test_logout.py` | `TestLogout` | выход из аккаунта |
| `tests/test_create_ad.py` | `TestCreateAd` | создание объявления неавторизованным и авторизованным пользователем |

## Запуск

```bash
pip install -r requirements.txt
pytest -v
```

Нужен установленный Google Chrome.
